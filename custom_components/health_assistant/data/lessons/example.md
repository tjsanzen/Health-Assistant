This is an example lesson. Every `.md` file in the `data/lessons` folder shows up as a card in the **Learn** tab. The card's title comes from the file name, so `intro_to_nutrition.md` becomes **Intro to Nutrition**. This first paragraph is the short description on the card.

## How lessons work

- Add a file, then reopen the Learn tab. You don't need to restart Home Assistant.
- Cards are sorted by file name. To choose the order, start names with a number, like `01_intro_to_nutrition.md` and `02_protein.md`. The number isn't shown in the title.
- If a lesson starts with its own `# Title` line, that title is used at the top of the article.
- Put images in the same folder and link them by file name: `![A balanced plate](plate.png)`.

## What you can write

Lessons use ordinary Markdown:

1. **Bold**, *italic* and `code`
2. Bulleted and numbered lists
3. [Links](https://www.myplate.gov), which open in a new tab
4. Quotes, tables and dividers

> Tip: keep each lesson short and about one idea. A 2–3 minute read works best on a phone between sets.
